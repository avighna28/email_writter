# Email Writer AI

A simple web app that helps you generate professional emails quickly using AI.

---

## Features

* Generate emails in seconds
* Formal and Informal writing styles
* Easy and clean user interface

---

## Tech Stack

* React.js
* Vite
* CSS / Tailwind
* AI API

---

## How to Use

1. Enter email details
2. Choose writing style
3. Click "Generate Email"
4. Copy and use your email
